# SAFI.md

Portfolio of Muhammad Safi ur Rehman. A puppet theater you scroll through.

Built with Vite, GSAP (ScrollTrigger) and Lenis. No framework.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Deploy

Import the repo in Vercel. `vercel.json` sets the Vite build and the `dist` output, so no settings need changing.
